## 🧭 Projeto em destaque — Método Norte

[![Método Norte](https://raw.githubusercontent.com/kasuowkl/metodo-norte-kit/main/docs/img/capa.png)](https://github.com/kasuowkl/metodo-norte-kit)

> **Dê um norte à sua IA.** Faça a IA desenvolver seus sistemas com consistência — sem alucinar tabelas, sem duplicar código, sem misturar projetos.

O **Método Norte** é um *starter kit* open-source que funciona como **roteador de contexto** para desenvolvimento com IA: uma documentação padrão que dá à IA o contexto certo, na hora certa. Extraído do uso real nos sistemas abaixo. Licença **[MIT](https://github.com/kasuowkl/metodo-norte-kit/blob/main/LICENSE)**.

➡️ **[Conheça o Método Norte](https://github.com/kasuowkl/metodo-norte-kit)** &nbsp;·&nbsp; ⭐ Se curtir, deixe uma estrela!

## 🧩 Sistemas

Todos seguem o mesmo padrão — HTML/CSS/JS, Node.js e SQL Server — e são desenvolvidos em coautoria com IA.
🔒 = código em repositório privado.

### 🟢 Em produção

| Sistema | O que faz | Stack | Acesso |
|---|---|---|---|
| **Portal WKL** | Portal corporativo com login único e perfis por setor: chamados, agendas, aprovações, finanças, projetos e tarefas, patrimônio e inventário | Node.js · SQL Server | [portal.grupowkl.com.br](https://portal.grupowkl.com.br/) 🔒 |
| **Na Levada** | Treinador de bateria gamificado: lê a bateria eletrônica por MIDI e avalia tempo e dinâmica de cada batida. Turmas, planos de estudo e estúdio de levadas | Web MIDI · Web Audio · Node.js | [nalevada.grupowkl.com.br](https://nalevada.grupowkl.com.br) 🔒 |
| **Central de WhatsApp** | Mensageria integrada aos sistemas: avisos, confirmações e atendimento com fila e histórico | Node.js · Baileys | 🔒 |
| **Explorador de Banco de Dados** | Navegação num banco de ERP, mapa de relações entre tabelas e IA que explica cada uma | Node.js · SQL Server · IA | 🔒 |
| **Monitor de Rede** | Monitoramento de equipamentos da rede por SNMP | Node.js · SNMP | 🔒 |
